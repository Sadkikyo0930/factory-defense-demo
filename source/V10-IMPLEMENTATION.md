## 运行与操作

`npm ci`、`npm run build`、`npm run preview -- --port 4190`。默认同一 Phaser/Vite 入口进入 V1.0；旧车间保留在 `?legacy`，可回放与回退，不删除旧模型、资源和导入工具。

1. 默认任务明确标为 **SYNTHETIC 演练**。左侧选择元素，点击加减按钮，或拖至对应阵地。阵地编号是实际可部署槽；VI 可自由部署编号 1～4，脱泡不部署员工。
2. 任务设置可以改期初 TV、独立新增 TV、目标、人员预算、COF、BD/POL 成功率、黑胶比例、候选评分权重。新增量编辑不包含 MNT；原始到料时间保留，新建合成批次在一小时到达。更细到料序列以 `Scenario.lots[].at` 配置。
3. 开战立即冻结情景与阵型，模拟整个十小时。约五秒动画后显示战绩；跳过只跳过动画，不重算随机结果。战中和结算阶段不能改布阵、设备、参数或导入；必须点击同情景重布阵。
4. 日报使用原来的本地解析、预览和确认入口。确认后替换初始快照，不叠加、没有新增 IN；FA 值单独保留。必须确认独立 IN 口径；有 POL 汇总时，还必须明确确认无需未知 TV 切割，并设置黑胶比例，不能把未知型号当已核实工艺。
5. 单局 JSON 包含冻结的 `scenarioSnapshot`、阵型、逐岗位流水、守恒结果、固定基准、反事实冗余、三项评分及版本/日期，下载在本机，不上传或写排行榜。

## 数值引擎

`src/v10/spec.ts` 定义工艺、单位、容量和情景契约；`engine.ts` 为纯离散事件引擎；`session.ts` 管理阶段锁与不可变快照。`Battlefield.ts` 和 `main.ts` 分别负责 Phaser 渲染与 DOM 界面，动画不改变生产数量。

- WIP 批次是物料 ID 区间，队列、在制、OUT 和失败池分别持有不重叠区间。每局检查逐工序等式和全局实体、身份守恒。百万初始 WIP 不生成百万对象或精灵。
- 十小时内按真实到料、完成事件调度，每项服务占用一个实际岗位资源；班末未加工完的物料仍计在对应阶段 WIP。时间不会为每道工序重新从零计算。
- 贴胶是 800 COF/人/10h，用每批次 COF/片计算秒数；物理片数另算。
- 脱泡唯一机器，立刻取已有的最多八片混批，每批六百秒，不凭空增加员工。此为明确的可行“即时开批”策略，不是最优等批策略。
- TV 的固定人工作业槽数沿用确认清单；没有 FA 塔、手撕塔、特殊多能工或战中调岗。工位停用状态由情景配置并在开战冻结。
- VI/OUT 同四个 VI 资源，VI 120 秒/TV片，OUT 另耗原模型的 120 秒/片；优先发出已检查的 OUT，轮转选择空闲操作位。不能得到 300+300 的双重免费能力。
- MNT 只在共享脱泡和已有明确 MNT 切割条件下处理。不把未知 MNT 后段设备映射成 TV 设备；混批后的 MNT 物料停在其后段等待，仍保留身份。完整独立 MNT 人工工区尚不在本轮可布阵地图中。
- TV 条件切割数量/节拍未知时阻断该任务，不生成假设备；MNT 260片/人/10h、一个切割位只在明确启用的数值情景中支持。
- BD/POL 仅在 VI 终点按 seed、来源 ID、批内序号、轮次判一次；失败进入独立本轮池，不自动返修循环。PI/VI 未分型存量只经过合法后段，不猜 BD/POL 身份或成功率。
- 覆膜/过判成功率 100% 为默认演练值，可在情景 `yield` 修改；不是现场成功率结论。

## 评分

默认候选权重 60/25/15，可在任务设置改变，合计须为100；逐岗位重要性可通过 `Scenario.importance` 配置，默认等权。不是员工正式绩效评价。

固定 potential 是原情景所有合法后续工序的物理潜在流入上界，与玩家是否断料无关。OUT 基准为同种子、同资源上限、满合法部署的实际可行十小时调度，不宣称数学最优。基准不消耗玩家预算，目的为同情景统一归一化。

按固定岗位顺序、槽位降序逐个撤人并完整重跑，只有所有期末不超过 `max(原期末,目标)` 且成功 OUT 不减少才判冗余，并遵守 `minimum`。单人闲时很多不直接扣人力分。无人时兵力分为0；无可完成 OUT 基准时产出项按满分，其他项照常计分。总分保留一位小数。

附件的 A100/B57.5/C90 仅作为三站简化数学测试，独立于完整离散事件测试，不能拿链完成冒充真实 OUT。

复用旧背景、设备、十种角色及 idle/work 图集。新增唯一 `public/v10/monsters-atlas.png`（1254×1254，约1.66MB，四帧透明 PNG）；由内置图像生成工具制作，实际四帧尺寸运行时从纹理计算。未引入 3D 或新运行依赖。图集生成规格：四个严格2×2、同一斜正面视角的 Q 版科幻维修怪物，分别蓝金属装甲、金色薄膜泡、青绿破膜卷、紫色幻影，独立透明边缘、无文字或背景。概念图本身没有作为战场底图或资源提交。
