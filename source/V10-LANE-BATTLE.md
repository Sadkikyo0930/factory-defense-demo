# V1.0 战场与分路进攻

本轮分支为 `feature/v10-lane-battle`。指定 V1.0 基线为远端 `cac4f3707300b0ca5b3b678d40a941ca1e84ca52`，本轮前一版战斗优化为远端 `466dac2d78df5772f1e634add992ff347913778c`、本地 `ad065c28b45dbd440f21d321de925d3886cdc236`。本轮沿用该后续版本的加工记录投影和素材。

布阵区单独滚动。1280×720 时面板约 333px，岗位 16px，头像区域 42×50px，加减按钮 44×44px。达到工位或预算上限会禁用加号并提示原因。场地上保留工位编号和元素底座。共享脱泡呈现为自动雷阵，设备容量沿用模型。战斗区按实际部署展示角色，同岗位多人并排，攻击来自加工记录对应的操作位。

四条横向路线承载最多 12 个代表分队。三波安排在约 0、1.1、2.6 秒开始。分队进入后持续左移，怪物纹理显示尺寸由 205 降至 137 逻辑像素。代表分队沿用真实物料身份、工序记录与最终归属，压缩到约五秒内呈现，保持工序与成败对应。每只怪物只显示当前工序的无数值血条。火元素采用火球和火花，其他元素保留各自的运动与破盾特效。

战绩首页显示星级、大号总分、三项候选得分和关键表现。星级是展示层评级，50、70、90 分分别进入一、二、三星。可展开「生产复盘」查看详细流水和失败返修。评分权重 60/25/15 及公式沿用原版。

## 验证

- TypeScript 与 Vite 生产构建通过，目标为 Chrome 109。保留既有 Phaser 大包提示。
- 25 项 V1.0 模型测试通过。动画投影测试对比原引擎在 VI 0～4 人阵型的原生产字段、分项评分及冗余结果。报表和旧派工回归通过。
- Playwright Chromium 131 验证 1280×720、1600×900、页面缩放模拟、工位上限、预算、相邻卡片操作、四路线三波、11 类技能、无数字血条、真实成败、自动结算、同阵重战与 Canvas 降级。
- Windows 7／Chrome 109 实机、公司电脑稳定 30 FPS、手机远程客户端仍待实测。构建目标与 30 FPS 上限不等于实机性能验收。报表回归使用合成数据。

构建包解压到静态 HTTP 目录后即可访问。源码增量以对应项目源码目录为根，仓库中为 `source/`。线上站点仍使用原发布版本。
