# V0.7.1 人员到岗派工与初始 WIP 验收候选

开发批次：2026-11-17～18。分支 `feature/v071-staffed-dispatch`，基线 `4f3dccdc7e65cf75efa934297737f1a76347b410`，对应上一轮 `factory-defense-v071-format-delta.zip`。仅本地开发；不合并 main，不发布 Pages。

## 本轮行为

产品先到对应工区的公共物料位；派工器按 FIFO 取料，并在各设备间轮转。只有员工已经到岗、设备可用、没有在制/接料预约、且产能已确认或配置的工位才能领取。接料期间占用一个预约但不累计加工时间；到料后才加工。所有可用工位繁忙时，产品保留在公共 WIP 中，不分配给空人位。

VI 固定四个人工位。0～4 人分别决定 0～4 个可派工位；VI2/VI4 有人时只有这两位领料。VI 和 OUT 共用人员及待处理区，OUT 处理使用既有模型的 120 秒/片，无独立新增员工。期初 OUT、期初完成、新 IN 完成继续分开统计。

所有人工工序统一检查人员和设备状态：FA、祛除、贴胶、BD、UV、机器撕 POL、额外手撕、贴 POL、共享脱泡、黑胶、贴膜、PI、VI/OUT。机器撕与额外手撕共用同一 FIFO 队列；唯一脱泡机可领取最多八片 TV/MNT 混批。

调走或撤下员工后，原设备停止领取。已经开工的产品和剩余时间留在原设备，暂停而非转移或完成；重新派人并到岗后继续。尚在接料途中的预约会取消，产品沿通道返回原公共物料位，不复制、瞬移完成或丢弃。员工回到左下角「待命人员」区，可拖回岗位或先选中再点击空工位；复用同一员工编号和历史工作量。人数统计不因回派创建重复员工。

点击岗位可查看就绪、接料、在制、剩余时间和工区 WIP，并可手动「停用工位 / 恢复工位」测试设备不可用。没有新增随机故障规则。设备停用与人员缺席独立计算，均暂停在制进度。

公共待料只在工区物料位显示一次。大数量使用已有产品图标和精确数字；详细产品对象最多 96 个，每个工区最多展示 6 个排队图像，其余留在精确计数池。设备、员工、在制预约分别建模；`audit()` 检查人员归属、工序归属、重复领取、负库存及 TV 初始/新增/MNT 三套守恒关系。

## 初始日报快照

上一轮格式诊断、XLSX/XLS/XLSB/HTML/XML 读取、PowerShell + Excel COM 只读提取、UTF-8 JSON、岗位映射和导入预览原样保留。本轮未修改这些源码、工具或正式美术文件。标准文件与兼容格式仍通过同一 Worker、同一岗位映射接入生产队列。

- 只取「岗位/岗位明细 → WIP情况 → 今日实绩」，不使用目标、昨日、BAL 或出勤列。
- 黑胶直接取数；缺失贴胶为 0；POL 默认 20%/80%，比例可调整且整数合计守恒。
- 白夜班快照去重，不相加；不一致、空白、非法值由预览要求确认。
- 确认前不应用；重复导入替换快照，不叠加。班次开始后允许读取预览，但模型拒绝替换，保留完整运行记录，须重置后再设期初快照。
- 初始 WIP 不计作新 IN；FA 共享数量不擅自归 TV，单列显示并保留。

## 明确的现场待确认项

FA 暂设一个**共享分析演练位**，不是声称已确认现场 FA 人数/设备数量。FA 专属美术尚缺，复用已有 PI 人物；标签明确标记演练。FA 90 秒/片沿用原型 90 秒入流节拍作为可配置演练值，不是正式 FA 产能。新增 TV 和失败返修必须通过有人的 FA；日报 FA 共享快照因未确认 TV/MNT 归属，继续保留，不自动送入 TV 流程。

额外手撕产能仍默认空白，组长设置演练值后才能加工，不凭空承诺现场产能。BD/POL 成功率、COF 均为已有可配置演练参数。PI/VI 汇总快照没有维修类型时沿用既有后段演练口径，不猜测其前段工艺或返修率。切割数量仍待确认，需求会进入待确认状态，不创建虚构切割机。

## 运行与实机验收

增量包覆盖当前完整 V0.7.1 工程对应文件，不是独立项目，不含 `node_modules`。源码运行：`npm ci`、`npm run build`、`npm run preview -- --port 4174`；可运行构建包须通过本地静态 HTTP 服务打开，不要双击 `index.html` 使用 file 协议。现有预览仍在 4174，本轮无公网发布。

实机先读取日报并核对预览；不能解析时可按 `tools/daily-report/README.md` 使用可选只读提取工具，执行策略阻止时交 IT 审核，不绕过。确认后检查 WIP/FA/OUT 与日报一致。只部署 VI2/VI4，确认其他位不领料；运行一段时间撤人、观察剩余时间不变，再回派；停用/恢复工位；最后试跨岗及机器/额外手撕共用队列。运行中的快照导入应被拒绝，已有生产记录必须保持。
