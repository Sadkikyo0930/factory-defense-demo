# V0.7 本地日报 → 初始 WIP

基线：`ae8b8f65bbaeafe4e044ad2c97a1b7aef6c4cbc6`；开发分支 `feature/v07-local-report-import`。本轮只改独立测试工程，没有推送/发布网站。历史 README、V02–V06、既有测试记录均保留。

## 使用

`npm ci` → `npm run build` → `npm run preview`。选择顶部「导入日报」，读取 XLSX / XLS / JSON，核对日期、原始岗位、数值与异常，调整 POL 撕除比例，勾选后确认。也可选「手动设置」。只允许班次开始前替换；开始后需先结束或明确重置。重置/「应用并重置」清除本班导入和员工排布。

文件通过 File API 读取，SHA-256 仅在本机计算，SheetJS 0.20.3 在独立 Worker 解析；无上传接口、无 COM、无文件写入、无解除文件锁/关闭 Excel。第三方库来自官方 CDN（https://docs.sheetjs.com/docs/getting-started/installation/standalone/），由 Vite 打包成本地 Worker，不依赖运行时 CDN。限制 20MB 文件、20万单元格工作表、15秒解析超时。失败保留现有模型，提示另存副本或 JSON 中转。

JSON 备用格式（数值仅演示）：
```json
{"date":"2026-11-17","rows":[{"name":"TV祛除","today":28},{"name":"TV VI","today":59}]}
```
未提供的岗位在预览中标记缺失并暂填0，必须人工核对。可使用 `tests/fixtures/sample-demo.json` 查看完整演示数据。

## 解析与计量口径

- 优先唯一「常规日报」；否则按严格「岗位 / 工序 → WIP情况 → 今日实绩」表头发现。WIP表头无匹配或存在多个候选时拒绝猜测。最多扫描前40行表头。人员出勤今日实绩、目标、昨日实绩、BAL均不参与。
- 展开合并单元格；相同白/夜班快照去重，不相加。不同值、空白、负数、非整数要求补充确认。明确零值保留。日期不一致/缺失必须选定日期。未映射/MNT岗位列在预览中，不静默纳入TV。
- 保存文件名、文件指纹、日期、工作表及原始岗位名称。同一文件重复导入是替换初始快照，不叠加。
- 演示夹具合计311：TV250 + FA共享61。REMOVE28、BD66、UV5、POL6、FILM23、PI16、VI59、OUT4、BLACK43；TAPE0。POL采用 `Math.round(总数×比例)` 给撕除，余数给贴附，默认6→1+5。两个撕除人员位共享同一队列。
- FA共享61保留在共享未分配池，不作为TV新增投入。黑胶43保留共享原始来源，目前仅TV模式使用；将来增加MNT日报导入前仍需跨模式来源去重策略。
- VI59和OUT4分别进入同一个VI工区服务池；4个VI人工位共享，不复制59。画面显示共享待检/待OUT数，OUT由VI员工处理。初始OUT完成与本班新增OUT分开计数。
- 初始产品从已到达工序继续后续路线；不会回填FA新增IN或重复先前加工。BD后续仍经UV、PI、VI；POL后续仍经共享脱泡及条件黑胶，切割需求仍停待确认区；贴胶按现有COF产能，期初0不取消后续工作量。
- 期初PI/VI报表无维修类型：目前按已到站阶段继续演练，不猜测BD/POL比例，因此不能恢复这部分的真实返修概率。上游可识别BD/POL产品保留现有演示成功率/返修逻辑。没有把这种信息不足标为真实工艺验收通过。
- `initialPending` 为精确整数蓄积池，`products` 最多96个详细对象；每个导入工序保留少量队首，画面用少量产品图标＋工区总数显示大WIP。不按片数创建大量Sprite。
- 守恒：`初始TV = 初始未物化 + 在途/排队/加工初始产品 + 初始完成`；`WIP = 新IN + 初始TV - 新完成 - 初始完成`。FA共享与TV分开。进入各工序不会增加IN。原始期初OUT4始终独立追踪。

## 未验收 / 限制

实际帆软Excel尚未提供：真实表头、加密/保护文件、公式缓存、多页报表、真实白夜班及公司文件锁情形尚未实测，不能声称正式日报已通过。对无法安全识别的文件明确拒绝，使用JSON中转或人工核对。导入不是持久数据库，刷新页面仍按既有行为重新开始。

构建目标保持Chrome109、TypeScript ES2018。本轮使用的File.arrayBuffer、Worker模块、WebCrypto、dialog及DOM接口均在Chrome109支持范围；Windows7/Chrome109未真机实测。也未在公司低配电脑测帧率。既有模拟详细对象上限在极端混合负荷下仍是近似调度模型，不能据此直接承诺正式产能。

测试夹具均为截图数值合成，不含公司实际文件。无新增美术，保留现有素材与人员动画。
